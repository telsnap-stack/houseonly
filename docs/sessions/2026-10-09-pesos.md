## Regla común — `houseonly-worker/src/lib/vinyl-weight.mjs`

`peso = 0,15 kg de embalaje + discos × (12"/LP 0,30 · 10" 0,20 · 7" 0,08)`,
+0,20 si es box set, redondeado a 2 decimales. Sin ningún dato de formato:
**0,45 kg** (un 12" suelto). Regla revisada el 10-10: la primera (0,25 por 12",
0,40 por defecto) dejaba un 3LP en 0,90 y bajaba de tramo. En gramos todo es
múltiplo par de 10, así que **ningún peso calculado puede caer en 0,90**, el
borde del tramo (hay un test que recorre las combinaciones).

- `pesoDesdeDiscogs(formats)`: solo cuentan los formatos de tipo Vinyl (CD,
  cassette e insertos no). Un 10" LP cuenta como 10". Un vinilo sin tamaño se
  cuenta como 12" y se marca `TALLA?`. Sin vinilo devuelve `null` y no se toca.
- `pesoDesdeTexto(...)` / `gramosDesdeFormato(...)` para los importers:
  "2x 12\"LP", "3LP", "2xLP", "Double LP", "3x12 inch", "Triple", 7", 10",
  "Box Set"… Las cifras de un número de catálogo no se toman por discos.
- Tests: `test/vinyl-weight.spec.ts` (16). Suite del worker: 389/389.

## Script — `scripts/set-weights-from-discogs.mjs`

- `sku:{SKU}` de SYNC_STATE (prod, con wrangler: `kv key list` + `kv bulk get`
  en lotes de 100) → `listing_id`. El release sale del inventario público de
  Discogs (de una vez) y, para el resto, de `/marketplace/listings/{id}`.
  En KV no se guarda el `release_id`.
- Releases de Discogs cacheados en SYNC_STATE (`discogs-release:{id}`, `kv bulk
  put` cada 50): repetir el dry-run no los vuelve a pedir. Rate limit según
  las cabeceras `X-Discogs-Ratelimit-Remaining` (25/min sin token, 60 con
  `DISCOGS_TOKEN`). Timeouts y reintentos, porque esta red corta.
- Peso actual y título: de la Storefront (expone `weight`/`weightUnit`). Al
  aplicar: Admin API, `productVariants(sku:…)` → `inventoryItemUpdate(input: {
  measurement: { weight: { value, unit: KILOGRAMS } } })` (scope
  `write_inventory`), con 300 ms de pausa. Reanudable: si el peso ya es el
  calculado, se salta.
- **Marcas** (por la memoria discogs-match-needs-manual-approval: un release
  equivocado da un peso equivocado). `--commit` **no** aplica las dos primeras
  salvo con `--incluir-dudosos`:
  - `DRAFT`: el listing de Discogs no está publicado; puede venir del
    auto-listado sin revisar.
  - `DISCREP`: el título dice otro número de discos, o el peso actual (si no es
    el 0,5 genérico) implica otro número.
  - `TALLA?`: el release no dice el tamaño del vinilo.
- Uso: `node scripts/set-weights-from-discogs.mjs` (dry-run, tabla + CSV) ·
  `--commit` (pide `SHOPIFY_ADMIN_CLIENT_ID/SECRET`) · `--limit N` · `--out`.
